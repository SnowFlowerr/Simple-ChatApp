# 🧠 Simple-ChatApp

A sleek and functional React-based chat interface with editable and deletable messages, smooth UI, and localStorage persistence.

## ✨ Features

- ⚛️ **React Functional Components**
- 💬 **Chat with message history**
- ✏️ **Edit/Delete user messages**
- 💾 **Persistent messages via localStorage**
- 🎨 **Modular CSS for scoped styles**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/snowflowerr/Simple-ChatApp.git
cd chatsphere
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Your app should now be running at `http://localhost:3000`.

## 🧩 Components

| Component       | Description                                |
|----------------|--------------------------------------------|
| `ChatApp`       | Root component managing state & logic      |
| `ChatHeader`    | Displays the title and assistant label     |
| `ChatMessages`  | Renders chat bubbles with Edit/Delete      |
| `ChatInput`     | Input field + Send button                  |
